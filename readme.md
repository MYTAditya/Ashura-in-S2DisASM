# Ashura in Sonic the Hedgehog 2 (16-bit) Disassembly

This is a modified version featuring [Ashura the Hedgehog](https://info.sonicretro.org/Ashura) as protagonist, replacing Sonic the Hedgehog's Palettes and some other palettes.

[![Get it on GameJolt](https://img.shields.io/badge/Get%20it%20on%20GameJolt-CCFF00?style=for-the-badge&logo=gamejolt&logoColor=000000)](https://gamejolt.com/games/ashura-rom-hacks/1051404)

For an overview of the folder structure, [refer to this page](https://info.sonicretro.org/SCHG_How-to:Disassembly_Folder_Structure#Sonic_2).

Also See: [info.sonicretro.org/Disassemblies](https://info.sonicretro.org/Disassemblies)

To build this, use build.bat if you're a Windows user, or build.lua otherwise. The built ROM will be called 's2built.bin'.

The Lua script requires Lua version 5.3. Earlier versions will cause errors about integer divisions ('//') and bit-shifts ('<<', '>>') not being recognised.
